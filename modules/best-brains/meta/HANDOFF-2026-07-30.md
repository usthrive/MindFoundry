## 3. Level C: the diagnosis is already done — do not repeat it

`npx tsx scripts/bb-readability-test.ts --level C` fails **all 24 weeks**, 12%–43%
of child-facing sentences over the 15-word ceiling, worst a **60-word** prompt.

**This is NOT the Level-B story.** Level B's failures came from two shared helpers
(`lib/metacog.ts` welded eleven words onto every probe; `lib/clock.ts` cleared 90%
of one week). Fixing two files fixed the level. **Level C has no such poisoned
helper** — it was authored to a looser standard throughout. Measured by surface
over 24 weeks × 6 seeds:

| surface | over | share | worst |
|---|---|---|---|
| `item.hint` | 5778 | **50.2%** | 32w |
| `item.prompt` | 2966 | 18.1% | 60w |
| `script.say` | 1002 | 44.5% | 50w |
| `explanation.whyBeforeHow` | 576 | **81.4%** | 71w |
| `explanation.summary` | 306 | 64.6% | 50w |
| `puzzle.hint` | 216 | **73.5%** | 33w |
| `GE.teacherSay` | 318 | 34.4% | 45w |

What makes it tractable: **hints are seed-invariant**, so those 5,778 sentences are
roughly **960 distinct strings**. Prompts are templated, so the fix is per-template
not per-draw.

Suggested shape: **3 agents × 8 weeks**, run one at a time (see §7), prose-only —
no drawn number, answer, option set or draw logic may change. Two short sentences
beat one long one at this age. The Level-B pass is the model: `git show` the commit
"Best Brains: … prose pass" for the register that worked.

## 4. The gates — all of them, and what each is for

Run from `frontend/`:

```
npx tsx scripts/bb-verify-packs.ts          # 19,782 assertions; the correctness floor
npx tsx scripts/bb-qg11-test.ts             # embedded-claim regression suite
npx tsx scripts/bb-qg12-test.ts             # surface-realism regression suite
npx tsx scripts/bb-readability-test.ts --level C   # the band sentence law
npx tsx scripts/bb-answer-entropy-test.ts --level C # can a child score it WITHOUT the maths
npx tsx scripts/bb-qg11-power-test.ts       # does QG-11's pin actually discriminate
npx tsx scripts/bb-cross-week-test.ts --strict     # corpus-level imitation
npx tsc --noEmit                            # ~800 MB — see §7
```

**Three of these gates were found this session reading fields that are never set.**
Each reported a clean pass over an empty set:

- the entropy gate's `CERTIFYING` filter → hid 28 real tells behind green;
- QG-11's choice arm matched by **substring**, so a keyed `"8:30"` accepted a truth
  of `"8"` → 11 of 1500 audited slots were green and not load-bearing;
- the readability gate looked for `say`/`text` on guided-example steps, but they
  carry **`teacherSay`/`childDo`** → it had never measured a single guided example.

The tell each time was **a suspiciously perfect number nobody doubted**. If a
detector never fires across a whole corpus, suspect the detector.

## 5. Non-negotiables — these are laws, not preferences

- **Answers are code-computed, never authored.** A wrong key must be structurally
  impossible. Embedded claims are pinned via `verifyFor` so QG-11 recomputes them.
- **`lib/format.ts` is the single interpolation authority.** No prompt interpolates
  a raw quantity, price, unit or article with a bare `${…}`.
- **Child-safe:** never a %, a red mark, "fail" or "Review" on a child surface. The
  module skin only remaps *semantic* error classes, so a literal `red-*` in a shared
  component leaks straight through. (This is why the Kumon `WorksheetProblem` /
  `WorksheetView` components **cannot** be reused here — they are full of literal
  `red-500`, they grade, and one renders the correct answer. The clean reusable
  pieces are the whole `services/ink` pipeline and `WorksheetNumberPad`.)
- **Seed-invariant hints** — fixed, role-based, name-free, number-free.
- **A figure must never hand over the answer it asks for**, and never short-circuit
  the strategy the week teaches.
- **Commits: pathspec-only, never `git add .`**, and never touch the 13 pre-existing
  untracked files (`video/`, `qa-screenshots/`, `qa_screenshots/`, `PLAN.md`, the QA
  reports, `docs/*.md`, `frontend/dev-dist/`). **Present a commit plan and get
  approval before committing. Ask before merging to `main` — it deploys to
  production.**

## 7. Resource limits — this is not advisory

The VM is **4 GB / 2 cores**. One `npx tsc --noEmit` peaks at **~800 MB / ~110 s**.
Over-subscribing killed roughly a dozen agents and the session itself earlier in
this project, at 300–450k tokens each.

```
npx tsx scripts/bb-agent-budget.ts     # run BEFORE any fan-out; obey the number
```

It has printed **1** all session. The working pattern:

- **one agent at a time**, and **forbid the agent from running `tsc`** — have it use
  the cheap `tsx` sweeps and typecheck it yourself afterwards. (This caught a real
  error in B7 that no sweep could.)
- never `npm run build` / `npm run dev` / the figure-render suite inside an agent.

## 8. Open decision for the owner

**`content_version` is written to `bb_week_state` and never compared anywhere.**
It was designed as the guard and the comparison was never implemented. It does not
bite on a deploy the child has not started against — but item ids are **positional**
(`B16-D4-05`) and drive reteach targeting, so on the *next* content deploy a child
mid-week would have their completed marks and miss-history silently re-pointed at
different questions. Policy needed: restart the affected week, or accept the drift.
