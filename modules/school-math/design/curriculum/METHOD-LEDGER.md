# METHOD LEDGER — school-math beside the Kumon-style and Best Brains-style modules

**Written 2026-11-17, 20:10 EST (from `date`), by the Curriculum Architect. Phase 4, Part A.**
**Status:** binding (HANDOFF §8; DD14). Every skill in Part B's grade map that another module
touches must have a row here; the gate "method ledger" (HANDOFF §12) checks it.

**The rule.** One method per skill per module. This module teaches **its** way; the first time
the skill appears, and whenever the child uses a sister method, the teacher says the **link
sentence** in that row, once, in plain words. The module **never adds a third, unconnected
method**: every "this module's way" below is either the sister method with its meaning made
visible, or a model that ends in the sister method's notation. The parent is never asked to
teach a second method (TAD §3.12).

**Sources.**
- *Kumon-style way* and sheet ranges: the app's own map, `frontend/src/services/generators/
  concept-availability.ts` (level + first worksheet; e.g. B41 = Level B sheet 41). Kumon never
  covers word problems (until Level F), models, time, money, measurement, geometry, data or
  "explain" (E198). The child is at Level C, with ×2–×9 in hand (E207); his sheet number (~C56+)
  is read from the app's own record.
- *Best Brains-style way*: the app's own `modules/best-brains/design/curriculum/CURRICULUM-MAP.md`
  (Level × week, e.g. B13 = Level B week 13; C = Level C; D = Level D). The child is at B6 (E239).
- *This module's way*: METHODOLOGY-MODEL §3 and DESIGN-DEFAULTS; every entry `[original design]`
  unless an E-row is cited. Facts about the Singapore-style method cite E-rows.
- "—" = that module does not teach the skill. Grade = US grade where this module teaches it.

**Vocabulary note (binding, E200).** In this module "number bond" means the part-whole
diagram. Memorised sums are "facts". The Kumon-style module's "bonds" are facts.
