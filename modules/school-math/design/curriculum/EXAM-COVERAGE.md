## §3 Scoring, review and the parent view

- **Scoring** is by code from each item's computed answer; the bar builder is graded against the
  item's schema (DD7); `truth` rows are graded; `explain` text is read formatively from the
  item's own rubric and never moves a point (TAD §7). Any sound method earns the answer mark on
  solve items; the model mark comes from the model (DD9).
- **Feedback held** until the last item; then **review**: each miss walked with the ladder (what
  it means → use what you know → a way to finish → the answer); one re-attempt allowed; the score
  unchanged (DD11; TAD §3.9).
- **Comebacks:** every missed part returns at about 2, 7 and 21 days with new numbers until it
  is right unaided three times in a row (DD10; TAD §3.13).
- **Parent view:** counts, never percents ("10 of 15 points; core 10 of 14, stretch 0 of 1");
  the items missed with his own answers; two category rows — *concepts and procedures* (A1–B5,
  C7) and *reasoning* (B6) — with the note that these are the module's categories, not the
  school's scale (DD11; E133, E262); the **exam-skills map** updated: for each of Q1–Q7 the state
  known / learning / not started (HANDOFF §8; METHODOLOGY §4); one small thing to try, offered,
  never assigned (TAD §3.12).
- **A mock pass is not "knows"** (METHODOLOGY §4): it is one day's evidence; the two-day rule
  still applies to every skill.
