## 0. How to read this curriculum

**The ladder.** Grade → unit → lesson → item (METHODOLOGY §7). A **grade** is a US grade (E16).
A **unit** is one topic, aligned to one school chapter or part of one, made of **lessons** (one
idea each) and closed by a **chapter check** (DD1, DD11). A **day** is a question count (N = 8 on
a lesson day, 10 on a practice day until the owner's O3 ruling), never a clock (DD1; TAD §3.11).
Weeks are not a unit here (DD1).

**IDs.** Unit = `G<grade>-U<two digits>`, e.g. `G2-U03`. Lesson = unit id + `-L<n>`, e.g.
`G2-U03-L2`. Stretch items = unit id + `-S<n>` (DD12). Chapter check = unit id + `-CK`. Entry
check = unit id + `-EC`. Items inside a lesson are numbered by the engine (Phase 4.5).

**A unit row** carries, in this order: id · title · the Common Core clusters it serves (E1–E5) ·
the school chapter it sits beside, as *chapter number and topic only* (E17–E21; DD2) · lesson
count · the model the child **builds** in it and the DD6 rung the unit reaches (read → label →
build → unaided) · the one heuristic practised inside its problems (DD15; grade sequence E268).

**Every unit, every grade, runs the nine-step loop** of METHODOLOGY §2: entry check → concrete
→ pictorial (the child builds) → abstract → guided practice with the help ladder → practice
days with returns → explain → chapter check with review → spaced returns. A clean entry pair
skips that idea's concrete step (DD3). "Knows" is earned only on practice days, two days, first
try, no scaffold (METHODOLOGY §4; TAD §2).

**Three kinds of unit.**
- **Core** — the school teaches the chapter at this grade and Common Core places it here.
- **School-beside, above grade** — the school's book teaches it a year early (EdReports flags,
  E25, E26, E37); the module teaches it when the school does, keeps the child's model one rung
  behind "unaided", and the parent page says in one line that Common Core places it a grade
  later. Districts often move or skip these chapters (E38), so the parent may hide the unit.
- **Module-own** — no single school chapter owns it; it exists because the child's test or the
  evidence demands it (G2-U03 the unknown part; G4-U03 bar models for the four operations and
  the algebra type). Each names the chapters it sits between.

**Stretch lane (DD12).** A unit may carry one or two `-S` items the school tests above grade.
Stretch never gates exit, never counts toward mastery, is recorded "stretch: learning / knows",
and returns as core in its home grade.

**What a grade file contains (the format B2 copies exactly).** (1) grade goals: Common Core
clusters, and where the Singapore order runs earlier or later, with E-rows; (2) the unit table
(this file's rows, repeated); (3) for **every** unit a lesson table with the columns *lesson ·
"I can …" · CPA path (concrete → the model he builds → abstract) · item types incl. the school's
formats (the format catalogue T1–T26, L1–L18, E134) · common wrong answer and the rule that makes
it · return target*, followed by one **Entry check** line naming the unit's two or three
prerequisite skills, each served as a pair and each with the lesson it comes from (DD3); (4) two
expanded units: teacher explanation covers · guided progression · a
practice day's anatomy · an original chapter check in sections A / B / C with every answer
worked; (5) the grade's stretch items; (6) entry and exit profile; (7) band notes (reading load,
read-aloud, touch and keyboard). GRADE-1.md and GRADE-2.md are the models. GRADE-2.md also
carries §0, the first learner's entry plan (DD5); later grade files have no §0.
